# InterviewPilot desktop

Windows-first Tauri 2 overlay for screen-based technical interviews.

## Run

Website API (default): `http://localhost:43123`

```powershell
cd E:\Taufique\Product\Crack\website
npm run dev
```

```powershell
cd E:\Taufique\Product\Crack_Interview\desktop
npm install
npm run tauri dev
```

1. Google login on the website
2. Open `/auth/desktop` and copy the one-time code
3. Paste the code in this app
4. Pick a mode + company pack, start interview, press Ctrl+Shift+S on the coding screen

Hotkeys: Ctrl+Shift+S screenshot · Ctrl+Shift+H hide overlay · Ctrl+Shift+C click-through
